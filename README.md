# Barq
# Godot 2D platformer prototype.

## مميزات المشروع
- حركة اللاعب: يمين/يسار
- قفز عادي
- قفزة مزدوجة
- أرضية بسيطة وبيئة جاهزة للتوسيع

## هيكل المشروع
```text
barq/
├── project.godot
├── icon.svg
├── README.md
├── .gitignore
├── scenes/
│   ├── Main.tscn
│   └── Player.tscn
├── scripts/
│   └── Player.gd
└── assets/
```

## التشغيل
1. حمل Godot Engine 4.x من الموقع الرسمي.
2. افتح هذا المجلد كـ Project.
3. اختر `project.godot`.
4. اضغط Play.
